## Base Work

This project builds upon:

- **Free-Lunch Enhancements for Multi-modal Crowd Counting** (CVPR 2025)
  - Authors: Meng et al., 2025
  - Repository: https://github.com/HenryCilence/Free-Lunch-Multimodal-Counting
  - Provides: U-Net cross-modal fusion architecture, Swin Transformer backbone, and training techniques (PPCA, RDS)

## References & Datasets

- **DroneRGBT Dataset**: https://github.com/VisDrone/DroneRGBT (Peng et al., 2020)
- **RGBT-CC Dataset**: https://github.com/chen-judge/RGBTCrowdCounting (Liu et al., 2021, CVPR)

## Libraries & Tools

- **PyTorch** & **Torchvision**: Deep learning framework and computer vision utilities
- **TIMM (Torch Image Models)**: Pre-trained model access and backbone implementations
- **Detectron2**: Baseline implementations for comparative evaluation (Faster R-CNN, RetinaNet)
- **Ultralytics**: YOLO baseline implementations
- **OpenCV**: Image processing and utility functions
- **Pycocotools**: COCO evaluation metrics for AP computation
- **ComfyUI**: Vision-language model integration for semantic segmentation experiments
